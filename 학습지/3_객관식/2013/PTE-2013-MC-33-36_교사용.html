3문항별 모의실험 (4개 — 문항마다 하나, 마우스로 돌리기·휠 확대)

333D 모의실험 — 33번 각운동량 중첩 상태의 측정 (벡터 모형 + 측정 시뮬레이션)

지도 팁: ① 두 성분의 m이 같으므로 L_z 측정값은 항상 ħ. ② L²은 2ħ²(l = 1, 확률 4/5) 또는 6ħ²(l = 2, 확률 1/5). ③ ⟨L²⟩ = (4/5)·2ħ² + (1/5)·6ħ² = 14ħ²/5. 새 창으로 열기 ↗

34모의실험 — 34번 상자 속 두 페르미온의 공간 파동 함수 |ψ(x₁, x₂)|² (2D)

지도 팁: ① 페르미온 전체 파동 함수는 반대칭: (공간 반대칭 × 스핀 대칭) 또는 (공간 대칭 × 스핀 반대칭). ② 스핀이 같으면 n = 1, 2를 하나씩 → 5E₁. ③ S = 0(단일항)이면 공간 대칭 → 둘 다 n = 1 가능(2E₁). 새 창으로 열기 ↗

353D 모의실험 — 35번 3차원 조화 진동자의 에너지 준위와 축퇴도

지도 팁: ① E = (n_x + n_y + n_z + 3/2)ħω — 바닥 상태 3ħω/2. ② 첫 번째 들뜬 상태: (1,0,0), (0,1,0), (0,0,1) → 5ħω/2, 3중 축퇴. ③ 슬라이더로 N = 2(6개), 3(10개) 껍질 확인. 새 창으로 열기 ↗

36모의실험 — 36번 상자의 왼쪽 1/3에 걸친 섭동: 1차 보정 (2D)

지도 팁: ① 1차 보정 E⁽¹⁾ = V₀ × (0 ~ L/3 구간에 있을 확률). ② 확률 = 1/3 − √3/4π ≈ 0.195 — 1/3(⑤)보다 작다(벽 근처는 |ψ|²가 작음). ③ V₀를 키우면 정확한 해와 1차 근사가 벌어진다. 새 창으로 열기 ↗
