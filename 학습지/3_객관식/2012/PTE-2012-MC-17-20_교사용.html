핵심 아이디어 — \(E_{\rm in}=\dfrac{kQr^2}{R^4}\), \(V(r)=\dfrac{kQ}R+\dfrac{kQ}{3R^4}(R^3-r^3)=\dfrac{kQ}{3R^4}(4R^3-r^3)\).
AI 풀이
1전하와 전기장

\(Q=\pi\rho_0R^4\), \(q(r)=\pi\rho_0r^4=Q\dfrac{r^4}{R^4}\) → \(E(r)=\dfrac{kQr^2}{R^4}\) (r ≤ R).

2전위

\(V(r)=\dfrac{kQ}{R}+\int_r^R\dfrac{kQr'^2}{R^4}dr'=\dfrac{kQ}R+\dfrac{kQ(R^3-r^3)}{3R^4}=\dfrac{kQ}{3R^4}(4R^3-r^3)\). 확인: r = R에서 kQ/R ✓

선지·보기해설
①가우스 + 전위 적분 ✓
②균일 밀도 구의 결과 \(\frac{kQ}{2R^3}(3R^2-r^2)\)와 혼동한 꼴(지수만 바꿈)
③적분 상수(표면 전위 kQ/R) 처리 오류
④⑤균일 밀도 구의 식 — ⑤는 ρ 일정일 때의 정답
정답 ①   \(V(r)=\dfrac{kQ}{3R^4}(4R^3-r^3)\) (정답표 ①)

▶ 20번 모의실험 보기

고등학생 지도 — 고교 수준에서는 ‘균일하게 대전된 구’(선지 ⑤)와 비교하여, 전하가 바깥에 몰릴수록 중심 전위가 표면 전위에 가까워짐(4/3 vs 3/2)을 그래프로 보여 준다.

3문항별 모의실험 (4개 — 문항마다 하나, 마우스로 돌리기·휠 확대)

173D 모의실험 — 17번 V = kr³ 중심력에서의 원궤도

지도 팁: ① F = −dV/dr = −3kr². ② mv²/R = 3kR² → ω² = 3kR/m. ③ U_eff = L²/2mr² + kr³, 원궤도에서 L²/2mR² = ½mv² = (3/2)kR³이므로 U_eff = (5/2)kR³. ④ 섭동을 주어 궤도가 원 근처에서 진동함을 확인. 새 창으로 열기 ↗

183D 모의실험 — 18번 유전체로 채운 구형 축전기

지도 팁: ① D는 자유 전하로만 정해진다(D = Q/4πr²). ② P = D − ε₀E. ③ r 안의 ‘총’ 전하 = 자유 Q + 안쪽 표면 속박 전하 −(K−1)Q/K = Q/K. ④ K = 1이면 모든 값이 진공 결과로. 새 창으로 열기 ↗

193D 모의실험 — 19번 매끄러운 탁자 위 용수철–질점의 회전

지도 팁: ① 라그랑지안 L = T − V, 탄성 퍼텐셜 V = ½k(r − a)². ② θ가 순환 좌표 → p_θ = mr²θ̇ 보존. ③ 라그랑주 방정식 mr̈ = mrθ̇² − k(r − a) = l²/(mr³) − k(r − a). 뉴턴 방정식 수치 해와 비교. 새 창으로 열기 ↗

203D 모의실험 — 20번 ρ = ρ₀r로 대전된 구의 전위

지도 팁: ① Q = ∫ρ₀r·4πr²dr = πρ₀R⁴. ② 안쪽 전하 q(r) = Q r⁴/R⁴ → E = kQr²/R⁴. ③ V(r) = kQ/R + ∫_r^R E dr = kQ(4R³ − r³)/(3R⁴). r = R에서 kQ/R로 연속. 새 창으로 열기 ↗

자주 나오는 오개념

  • “유효 퍼텐셜 = 원심 항” → V(r)도 더해야 함
  • “유전체 속 총 전하 = 속박 전하”
  • “라그랑지안 = T + V”
  • “전위는 전기장처럼 r에 대해 한 번 적분하면 끝” → 표면 전위(적분 상수) 잊음

  • F = −dV/dr, 원운동 조건을 쓰는가
  • D는 자유 전하로 정해짐을 아는가
  • 순환 좌표를 찾는가
  • 전위의 연속 조건을 쓰는가
