‘빛과 그림자’에 대한 다음 수업 과정을 PEOE(예상−설명1−관찰−설명2) 모형으로 재정리할 때, 각 단계에 해당하는 내용을 2줄 이내로 쓰시오. 단, ‘설명2’는 마지막 학생이 답해야 하는 내용 A를 포함하여 쓰시오. [4점]

교사 : 빛은 공기 중에서 어떻게 나아간다고 생각해요?

학생 : 휘어지지 않고 직진해요.

교사 : 그럼, 그것을 어떻게 알 수 있을까요?

학생 : 빛이 지나가는 길에 물체를 놓았을 때 생기는 그림자로 알 수 있을 것 같아요.

교사 : 그럼, 그림자에 대해서 좀 더 이야기해 보죠. 점광원이 아닌 광원으로 물체를 비추면 그림자의 모양은 어떨까요?

학생 : 그림자의 모양은 물체의 모양과 똑같을 거라고 생각합니다.

교사 : 왜 그렇게 생각해요?

학생 : 그림자는 빛이 지나가는 것을 물체가 가려서 생기니까, 그림자의 모양은 물체의 모양과 같겠죠.

교사 : 그럼, 직선 모양의 광원으로 원형인 물체를 비추면, 그림자의 모양이 어떻게 되는지 살펴봅시다.

[그림: 직선 모양의 광원 – 원형 물체 – 스크린]

학생 : 제 예상과는 달리 직선 모양의 그림자가 나오네요. 왜 그렇죠?

교사 : 만약 꼬마전구와 같이 점광원으로 원형의 물체를 비추면 원형의 그림자가 나와요. 그런데 꼬마전구가 위아래로 두 개가 있다고 하면 그림자가 어떻게 될까요?

학생 : 동그란 그림자가 위아래로 2개 나오겠죠. 아! 이제 알겠어요. 직선 모양의 광원은 점광원이 위아래로 연속해서 붙어 있는 것이라고 생각할 수 있겠네요.

교사 : 그래요. 그럼, 이제 어떤 것들이 그림자의 모양에 영향을 주는지 알겠지요.

학생 : 예! ( A )

1설명

직선 모양의 광원은 점광원이 위아래로 연속해서 붙어 있는 것으로 볼 수 있다. 점광원 하나하나가 원형 그림자를 만들고, 이 그림자들이 위아래로 연속해서 이어지므로 전체 그림자가 직선 모양이 된다.

2A

그림자의 모양은 물체의 모양뿐만 아니라 광원의 모양(과 광원·물체·스크린 사이의 거리)에 따라서도 달라진다.

3물리적 보충

엄밀히 말하면 선광원 앞의 작은 물체는 광원 전체를 가리지 못하므로 직선 모양의 ‘반그림자’가 생긴다. 그 길이 ≈ (광원 길이)×(물체–스크린 거리)/(광원–물체 거리) — 모의실험에서 확인.

답 직선 모양의 광원은 점광원이 연속해서 이어진 것이므로, 각 점광원이 만든 원형 그림자가 위아래로 이어져 직선 모양의 그림자가 된다. 따라서 A: ‘그림자의 모양은 물체의 모양뿐 아니라 광원의 모양에 의해서도 결정된다.’
자주 하는 실수

A를 ‘물체의 모양’만으로 쓰거나, 설명 없이 결론만 쓰는 경우. 설명2는 예상과 관찰의 차이를 해소하는 새 설명이어야 한다.

  1. 형광등(긴 막대 광원) 아래에서 연필 그림자가 흐릿하고 길쭉한 까닭은?
  2. 일식 때 본그림자와 반그림자 지역에서 보이는 모습은 어떻게 다른가?
  3. 꼬마전구 두 개를 가로로 나란히 놓으면 원형 물체의 그림자는 어떻게 될까?

6수업 활용 안내

수업 흐름 (45분)

  1. 예상 (5분) — 직선 광원 + 원형 물체의 그림자 모양 그리기
  2. 설명1 (5분) — 예상의 이유 쓰기(선개념 드러내기)
  3. 관찰 (10분) — 실험 또는 모의실험으로 확인
  4. 설명2 (15분) — 점광원 1개 → 2개 → 직선 광원으로 비계, A 도출
  5. 정리 (10분) — PEOE 단계 기능 정리

자주 나오는 오개념

  • “그림자 모양은 항상 물체 모양과 같다” → 광원의 모양·크기·거리에 따라 달라짐
  • “그림자는 물체에서 나오는 어두운 것” → 빛이 닿지 않은 곳
  • “광원이 크면 그림자도 무조건 커진다” → 본그림자는 작아지고 반그림자가 커짐

평가 포인트

  • 단계별 내용을 대화에서 정확히 찾는가
  • 설명1(선개념)과 설명2(새 설명)를 구분하는가
  • A를 일반화된 문장으로 진술하는가

실험 연결

막대 모양 LED, 꼬마전구 2개, 원형 물체로 같은 실험을 하고, 광원–물체 거리를 바꾸며 그림자 길이를 측정해 ℓ(D−d)/d 관계를 확인한다.
